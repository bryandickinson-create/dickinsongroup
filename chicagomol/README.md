# chicagomol

Protein art in 12 styles (stained glass, Chicago flag, Prairie School, Art Deco, the L, UChicago maroon & gothic, Burnham blueprint, Cloud Gate, Pilsen mural, Lake Michigan, deep dish, phoenix).

Open `index.html` (self-contained; `app.js` is the same script, kept for editing). Drop a PDB or mmCIF file on the page; with none loaded it shows a procedural TIM-barrel demo. Hide the background and export PNG, or TIFF in a zip, from the Export panel (downloads work only inside claude.ai's artifact viewer; elsewhere right-click the preview image).

Inspired by https://martin-steinegger.github.io/molart/
